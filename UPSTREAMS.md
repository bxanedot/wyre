# Upstream source

Wyre's desktop app in [`app/`](app/) is built on [MangoDisk](https://github.com/harry0703/MangoDisk) by harry0703 and contributors, version 1.1.9 at commit `f7d8bc73b68ec2170ac4ba451c6723b11329380c`. MangoDisk is licensed GPL-3.0-only. Its license is kept at [`app/LICENSE`](app/LICENSE), and the combined application is distributed under GPL-3.0-only.

Wyre keeps MangoDisk's storage, cleanup, privacy, application, startup, system optimization, maintenance and history features. Wyre adds a native network measurement command, native Windows and GNOME pointer controls, the macOS-style interface and SF Symbols from [GlyphStudio](https://github.com/bxanedot/GlyphStudio).

To compare Wyre with the original source, check out the commit above from the MangoDisk repository.
